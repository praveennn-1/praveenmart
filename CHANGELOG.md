# Changelog

All notable changes to the **PraveenMart** project are documented in this file following [Semantic Versioning](https://semver.org/).

- feat: implement Wishlist and Save-for-Later feature (O1), full Javadoc across service/DAO layers, Checkstyle/SpotBugs static analysis configuration, and complete final deliverables.

- feat: seller inventory management, product editing, admin user moderation, and search/filter by category and keyword.
